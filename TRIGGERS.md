# Triggers

When to check a film against the project it describes, and what to call.

This file is written for an agent: a Claude Code or OpenCode skill, an MCP
(Model Context Protocol, the protocol through which AI agents call tools in English) host, anything choosing a tool on someone's behalf.
Humans are welcome, but the routing rules below are the point.

---

## The generalisation, stated once

> **A video that states a fact about a project is the trigger.** Nobody says
> "please verify my claims". They say "make a launch video", "update the demo
> reel", "the site video is out of date", « refais la vidéo », or they hand
> over a storyboard with a number in it. The moment a film asserts *how many*,
> *how fast*, *how much*, it has acquired a fact that will rot, and this is the
> tool that notices.

The second trigger is silent, and is the one to remember: **the project just
changed.** A catalogue grew, a package shipped, a module merged into another.
Nothing re-reads a rendered MP4, so the film is now wrong and will stay wrong
until somebody looks. Run `verify_claims` after any change to the things a
film counts.

The third is narrow and concrete: **you are about to re-render.** Audit the
asset tree first. A render that fails halfway because a licensed music track
exists on exactly one disk is a worse discovery than the audit that said so.

Do not match on phrasings. Match on the closed vocabulary below, and only when
it is said **about a video**.

---

## The closed vocabulary

When one of these nouns appears about a film, this package is in scope:

- **claim**, assertion, "it says", "on screen", number, count, "how many"
- **stale**, out of date, outdated, wrong number, drift, « périmé »
- **asset**, footage, music, narration file, voice-over file, licensed, "where did X come from"
- **re-render**, re-cut, rebuild, regenerate, « remonter »
- **caption**, subtitle, VTT (WebVTT, Web Video Text Tracks, the caption file a browser player reads), « sous-titres »
- **poster**, thumbnail, preview frame, "the image before you press play"
- **loudness**, volume across a series
- **pitch**, problem, solution, secret sauce, "does the film explain anything"
- **second language**, translated cut, calque, « décalque »
- **script**, narration text, the writing charter

Two of these route *out* as well as in. Captions are built here but the file
is written by `video_helper.subtitles` in `video-helper`; SubRip (SRT) output
is `video_helper.vtt2srt`, not a command of this package. Narration audio is
generated by `sprezzature-audio`; this package measures it. Say so rather than
reimplementing either.

## Every tool, and the request it answers

| Tool | The request it answers |
|---|---|
| `verify` / `verify_claims` | "Is the number in this film still true?" Each declared claim against the file that decides it. |
| `scan` / `scan_composition` | "Is there a number on screen nobody declared?" Visible text of an HTML composition only. |
| `list_methods` | "How can a claim be checked?" The five source methods: `json_len`, `json_key_len`, `regex_count`, `line_count`, `literal`. |
| `assets` | "Can this film be rendered again from a clone?" Tracked, derived or sole, per file. `--restore` copies back absent tracked files only. |
| `captions` / `build_captions` | "Give me subtitles for this film." WebVTT from the narration script and the measured audio. |
| `poster` | "Give me a thumbnail / preview frame." One JPEG frame at a chosen time. |
| `pitch` | "Does the film explain itself?" Problem, solution, secret sauce, on screen or (`--voice`) in the narration. |
| `calque` | "Was the French cut written, or translated from the English?" |
| `prose` | "Check this script against the writing charter." Dashes, comma-and, negative openings, banned phrases. |
| `health` | "Is the server up?" |
| Library only: `post.bake_poster` | "Make this still the thumbnail feeds will show." Prepends it as frame 0. |
| Library only: `post.normalize_loudness`, `post.measured_loudness` | "Level the loudness across the series." -16 LUFS (loudness units relative to full scale), true peak -1.5 dBTP. |
| Library only: `timeline.lay_out` | "Where does each narration line land once it has been spoken?" |
| `skill` / `sprezzature-video-skill` | "Is the skill my agent reads up to date?" Reports; `--install` copies the shipped skill into `~/.claude/skills` (`--agent opencode`: `~/.opencode/skills`). |

## What to call on every surface

The MCP tool name is the route's `operation_id`. A dash means the surface does
not carry that operation. CLI (command-line interface) is the commands typed
in a terminal; HTTP (HyperText Transfer Protocol, the protocol a program uses to
ask a server for data) is the FastAPI app.

| Operation | Library | CLI (`sprezzature-video` or `make-film`) | HTTP | MCP tool |
|---|---|---|---|---|
| Verify claims | `verify_all`, `verify` | `verify SPEC --root DIR` | `POST /v1/verify` | `verify_claims` |
| Scan the screen | `undeclared_numbers` | `scan COMPOSITION --spec SPEC [--ignore ...]` | `POST /v1/scan` | `scan_composition` |
| List claim methods | `claims.Method` | - | `GET /v1/methods` | `list_methods` |
| Build captions | `captions.write`, `to_cues` | `captions SPEC --lang LANG [--translated]` | `POST /v1/captions` | `build_captions` |
| Liveness | `__version__` | `-V`, `--version` | `GET /health` | `health` |
| Audit assets | `AssetLedger.audit`, `.restore` | `assets SPEC --tree DIR [--restore]` | - | - |
| Poster frame | `post.poster` | `poster VIDEO --out FILE --at S` | - | - |
| Pitch | `from_spec`, `from_narration`, `check_pitch` | `pitch SPEC --duration S [--voice LANG]` | - | - |
| Calque | `compare_spec`, `compare_cuts` | `calque SPEC --from en --to fr` | - | - |
| Prose charter | `check_line`, `measure_prose` | `prose FILE --lang en\|fr [--strict]` | - | - |
| Bake poster, loudness | `post.bake_poster`, `post.normalize_loudness`, `post.measured_loudness` | - | - | - |
| Timeline | `lay_out` | - | - | - |
| The skill | `skill_path()` | `skill [--install] [--agent claude\|opencode] [--path]`, or `sprezzature-video-skill` | - | - |

The MCP server is `sprezzature-video-mcp` (default `127.0.0.1:8000`, endpoint
`/mcp`). The skill is `sprezzature-video`, shipped inside the package at
`sprezzature_video/skill/`; `sprezzature-video-skill --install` puts it where
Claude Code reads it. Five surfaces in all: library, CLI (Click), HTTP API
(application programming interface: the FastAPI app, with a Dockerfile and
`docker-compose.yml`), MCP (fastapi-mcp) and
the skill.

## What to call, in order

1. `verify_claims`: the declared claims against the code. Exit 1 means the
   film is lying; that is the gate. A spec with no claims also exits 1, and the
   route answers 400.
2. `scan_composition`: every number visible on screen that no claim accounts
   for. Without this half, only the numbers somebody remembered to declare are
   protected, which is never the one that drifted.
3. `assets`: can this be rendered again from a clone? Three classes: a copy
   away, a tool away, or nowhere else at all.
4. `build_captions`: from the narration script and the **measured** audio, not
   from a transcript and not from typed durations.

## Which neighbour

Several different questions get asked about the same film. They do not
substitute for one another.

| The question | Package | Tool |
|---|---|---|
| **Is it still true?** numbers, counts, quoted phrases | sprezzature-video | `verify_claims`, `scan_composition` |
| **Can it be rebuilt?** assets, narration files, licensed media | sprezzature-video | `sprezzature-video assets` |
| **What does it say, in text?** captions | sprezzature-video, file written by video-helper | `build_captions` |
| **What goes in the frame?** charts, diagrams | sprezzature-figures | `make-figure` |
| **What goes in the frame, geographically?** | sprezzature-maps | `make-map` |
| **How does it sound?** narration, voices, diarization | sprezzature-audio | `sprezzature-audio-narrate-kokoro` |
| **How do the pixels move?** timing, animation, render | Hyperframes, outside this package | not this package |

This package does **not** render. If the request is "make the video look
better", "add a transition", "animate this", it belongs to the renderer.

---

## When this package is the wrong answer

- **The video makes no factual claims.** A mood piece, a title sequence, a
  showreel. The apparatus here protects nothing.
- **The ask is motion design.** Particles, 3D, character animation: Remotion,
  Revideo, Hyperframes. See `LANDSCAPE.md`.
- **The ask is editing by hand on a timeline.** A declarative spec is the wrong
  shape for that work.
- **The ask is transcribing recorded speech.** That is `sprezzature-audio`.
